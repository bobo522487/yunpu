# ADR-0014: 谱文版本以服务器回答为准

客户端保存谱文时只提交当前期望版本，不在本地执行 `applyArticleVersionCas`。服务器返回 200 则接受这篇谱文，返回 409 则形成谱文冲突。本地那份比较只留给服务端契约测试。

## 考虑过的做法

在发出保存前用 `applyArticleVersionCas` 自己判断版本。那样客户端和服务器会各算一遍，而 store 今天也没有调用它。

## 后果

写入 module 的 port 只产生两种结果：已接受的谱文，或 409 时的服务器谱文。客户端不另作版本结论。

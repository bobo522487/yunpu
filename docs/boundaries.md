# 系统边界

家谱租户表的读取和写入只经过带租户身份的事务。下面三个入口不走那次事务，也不能被普通请求或普通后台任务借去读写租户表。

## 健康检查

单独的短连接，只执行 `SELECT version()`。

## 认证库

认证使用自己的连接，只访问认证库里的表，不查询家谱租户表。

## 迁移

迁移命令使用自己的连接，可以跨租户改表结构。请求处理和普通后台任务不能借用这条连接。

新增第四种例外时，必须同时改这份说明和 `specs/005-slim-architecture/contracts/tenant-entry.md` 所描述的入口。当前没有「提交成功后再删除外部对象」的产品写入。

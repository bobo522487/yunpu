# Contract: 控制台页面状态（加载 / 空 / 错误 / 权限）

**Feature**: `003-workspace-console` | **Date**: 2026-11-15

> 本文件是四页 + 组织切换器的状态契约，供实现与验收对照。对应 spec `FR-010`、`FR-015`、`FR-017` 与 `SC-003`、`SC-009`、`SC-010`。数据载荷见 [console-api.md](console-api.md)。

## 1. 通用状态机（每个页面一致）

```text
进入页面 / 切换组织 / 手动刷新
        │
        ▼
   loading ──显示骨架屏（PageSkeleton），不显示旧数据占位为「最新」
        │
        ├─ 成功且有数据 ──> ready（正常渲染）
        ├─ 成功且空 ──────> empty（空状态 + 下一步入口，无错误样式）
        └─ 失败 ──────────> error（页内 PageError：原因 + 「重试」按钮）
                              │ 点击重试 → 仅重发本页数据请求 → loading
```

规则：

- **error 不清空已渲染的既有数据**：页面已 ready 后的刷新失败，保留旧数据并在页内提示「刷新失败，点此重试」（`FR-017`）。
- **error 不跳登录**：只有 401（会话失效）才跳登录（`FR-014`）；两者不得互相误判（spec Edge Case）。
- **重试只发读请求**，绝不重复执行任何写操作（spec Edge Case）。
- 骨架屏形状与真实内容布局一致（列表页按行、首页按卡片组），避免加载完成时跳版。

## 2. 各页面状态定义

### 首页 `/home`

| 状态 | 表现 |
| --- | --- |
| loading | 概览数字区 + 最近项目 5 卡骨架 |
| empty | 「尚无项目」空状态 + 「新建项目」入口；成员/邀请数字照常显示（`FR-015`） |
| error | 页内错误 + 重试 |
| 权限 | 所有成员可见（`project.read` / `organization.member.read` 为全角色）；「邀请成员」入口对 viewer 隐藏 |

数字一致性：项目数、成员数、待处理邀请数与各自列表接口同一次进入页面的数据一致；并发变化导致的短暂不一致以服务端下次查询为准，不缓存冒充实时（spec Edge Case）。

### 项目页 `/`

| 状态 | 表现 |
| --- | --- |
| loading | 项目行骨架 |
| empty | 「尚无项目」+ 「新建项目」按钮 |
| error | 页内错误 + 重试 |
| 权限 | `viewer`：列表可见，新建/编辑/删除入口不渲染或禁用；`editor`/`admin`：全量。提交被服务端拒绝时显示服务端错误（双防线，`SC-003`） |

交互：新建/编辑用弹窗；删除用确认弹窗（说明后果，`FR-011`）；保存返回 409 `CONCURRENT_MODIFICATION` 时提示「他人已修改，请刷新后重试」，**不静默覆盖**。

### 成员页 `/members`

| 状态 | 表现 |
| --- | --- |
| loading | 成员表 + 邀请表骨架 |
| empty（成员） | 不会出现：至少含 owner；仍给出「邀请成员」入口 |
| empty（邀请） | 「暂无待处理邀请」文本，无错误样式 |
| error | 页内错误 + 重试（成员区与邀请区可独立重试） |
| 权限 | `viewer`：只读名单；邀请/改角色/移除/转移入口不渲染；`admin`+：全量；转移所有权仅 owner 可见 |

交互：创建邀请成功 → 弹窗展示 `inviteUrl` + 一键复制，关闭后列表不出现明文；移除成员/撤销邀请/转移所有权均需确认弹窗。

### 设置页 `/settings`

| 状态 | 表现 |
| --- | --- |
| loading | 两分区表单骨架 |
| error | 分区级页内错误 + 重试 |
| 权限 | 组织分区：`admin` 可改名，`admin`+ 可归档（按钮带后果说明）；`viewer`/`editor` 该分区只读展示；账号分区：任何角色可改显示名与密码（只对本人生效） |

归档成功 → 按 `FR-013` 自动切换到下一个可用组织；无可用组织 → 跳 `/onboarding`。

### 组织切换器（Sidebar 顶部）

| 状态 | 表现 |
| --- | --- |
| loading | 下拉列表骨架（首次进入） |
| empty | 引导状态不渲染切换器（四页整体被 `/onboarding` 替代） |
| error | 下拉内页内错误 + 重试；切换失败保持原组织并提示 |
| 行为 | 选中即 `activate`（切换即记住）→ 刷新四页数据；创建组织走弹窗（含建议名称选项）→ 成功后自动切换 |

### 引导状态 `/onboarding`

`session.onboarding === true` 时四页路由整体重定向至此；页面只有「创建组织」「接受邀请（token 或链接预填）」两入口，无四页导航（`FR-002`）。创建或兑换成功后进入新组织首页。

## 3. 全局横切

- **会话失效**：任一请求 401 → 清会话状态 → 跳 `/login`，不残留组织数据（`SC-009`）。
- **跨组织残留**：切换组织后，四页任何位置不得出现上一组织的名称、项目、成员（`SC-004`）；实现上切换后统一失效本地数据再拉取。
- **Mock 模式**：`MockModeIndicator` 显示时，以上状态机照常工作（Mock 也走 `apiRequest` 信封）。
- **只读成员绕过界面**：直接请求写端点必须被服务端 403 拒绝（`SC-003` 的服务端半边）。

# Contract: 三处权威

本契约描述维护者如何判断一份变更是否只改了权威定义。成功路径上的请求与响应形状不变。

## 存储

- 约束、触发器和行级策略的定义以新的迁移 SQL 为准。
- 同一次变更必须更新 Drizzle schema 中的同名约束。
- 只改其中一边的变更不被接受：集成测试按约束名对照数据库与 schema 源。
- 不要求更新编号索引、追溯矩阵或散文表清单。

## 对外形状

- 路由的类型权威是 `AppType`。
- 不新增手写的端点说明书。
- 本特性不改变合法请求的成功响应字段。

## 失败含义

- 状态码以 `ERROR_STATUS` 为准。
- 数据库失败进入 `mapDatabaseError`，按 SQLSTATE 与约束名选择错误码。
- 不解析数据库错误的消息文本。
- 不维护第二份错误对照文档。新增的 SQLSTATE 只加在这个映射函数和下面的拒绝契约里。
